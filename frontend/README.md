# SPAȚIU — frontend (React + Vite)

Marketplace pentru închirierea de spații (case, săli, curți, garaje, depozitare).

```
npm install
npm run dev
```

Datele (conturi, anunțuri, rezervări, mesaje, recenzii) se salvează în IndexedDB, în browser.
Din „Contul meu” sau din subsol le poți exporta / importa ca fișier JSON.
